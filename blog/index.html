EchoSparse: Letting Last Step's Statistics Steer This Step, Approximating at Multiple Resolutions Instead of Dropping, and Packing Sparse Attention Tightly

Building on PISA and Sol-Attn, EchoSparse uses the previous denoising step's LSE as a fixed softmax offset and its block masses to allocate 1, 4 or 64 columns per KV block instead of dropping any, then packs the fragmented representative columns into wide GEMM tiles and overlaps data movement with compute.

EchoSparse：让上一步的统计量为下一步指路，用多层级近似代替丢弃，再把稀疏 attention 排得更紧

在 PISA 与 Sol-Attn 的基础上，EchoSparse 用上一去噪步的 LSE 作为 softmax 的固定偏移，用块质量给每个 KV 块分配 1、4 或 64 列而不是丢弃，再把零碎的代表列拼成更宽的 GEMM tile，让搬运与计算重叠。
